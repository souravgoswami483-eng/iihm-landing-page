# Indian Institute of Hotel Management (Indian IHM) - Landing Page

A high-proficiency, responsive landing page for the **Indian Institute of Hotel Management (Indian IHM)** in Salt Lake City, Kolkata.

## Features

- **Degree & Masters Programmes (Interactive Tabs)**:
  - **Bachelor Programmes**:
    - Bachelor in Hotel Management
    - Bachelor in Hospitality Management
    - Bachelor in Culinary Management
  - **Masters / MBA Programmes**:
    - Masters / MBA in Hotel Management
    - Masters / MBA in Hospitality Management
    - Masters in Culinary Management
- **High-Contrast Hero Section with Ambient Video & Glassmorphism Form**:
  - Official Indian IHM campus video background.
  - Interactive admission counseling form with real-time feedback.
  - Dedicated video lightbox modal with sound & playback controls.
- **Why Choose Us**: Institutional pillars covering practical grooming, global placements, and celebrity masterclasses.
- **ADVANTAGE@Indianihm**: 12-point institutional excellence grid directly from `indianihm.com`.
- **Campus & Training Labs**: Highlights Food Production & Bakery Labs, 5-Star Mock Suites, and Smart Lecture Halls.
- **Industry Speak**: Featuring testimonials from Chef Ranveer Brar, Padma Shri Chef Sanjeev Kapoor, and Chef Balpreet Singh Chadha.
- **Our Alumni**: Authentic graduate placement records across Italy (P&O Cruises), UK, Goa (Club Mahindra), and New Delhi.
- **Smooth Interaction & Animation**:
  - Lenis smooth scroll integration via CDN importmap.
  - Parallax hero background.
  - Direct admission portal modal with course pre-selection.
  - Responsive mobile overlay navigation.

## Tech Stack

- **HTML5 / CSS3 / JavaScript (ES Modules)**
- **Lenis Smooth Scroll** (`@studio-freight/lenis` / `lenis`)
- **Google Fonts**: Plus Jakarta Sans & Outfit
- **No external build step or framework required** — runs directly in any modern browser.

## Getting Started

Simply open `index.html` in your web browser, or serve it via any static web server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js npx
npx serve .
```

Visit `http://localhost:3000` to view the page.
